# UI Design Plan: "Mocha & Amber" (Soft & Cozy Aesthetic)

## Overview

This design plan outlines the visual direction for the email generator template application. The goal is to create a "Soft & Cozy" aesthetic that reduces visual fatigue, feels premium, and provides a clear contrast between the application's interface and the email canvas being edited.

## Aesthetic Concept: Mocha & Amber

Instead of harsh blacks and pure whites, this design uses deep warm grays (mocha) for the dark mode background and a creamy bone white for the light mode. The primary accent color is a vibrant amber/terracota to guide user interactions.

## 1. Typography

- **Headings (h1, h2, h3, etc.):** `Outfit` (Google Fonts). This geometric sans-serif font has warm, friendly curves that make the application feel modern and approachable, moving away from a strictly corporate look.
- **Body & UI Text (paragraphs, buttons, small text):** `Geist` or `Geist Mono` (already in the project). These fonts offer maximum legibility for dense UI panels and code editors.

## 2. Color Palette (CSS Variables)

We will modify the Shadcn UI `globals.css` to implement this palette.

### Dark Mode (Default)

- `--background`: `#1c1917` (Deep Mocha / `stone-900`) - The main application background.
- `--card`, `--popover`: `#292524` (`stone-800`) - Sidebar panels, floating menus, and toolbars. Slightly lighter than the background to create depth.
- `--border`: `#44403c` (`stone-700`) - Subtle borders to separate panels without being distracting.
- `--primary`: `#d97706` (Amber / `amber-600`) - Primary buttons, active states, and drag-and-drop drop-zones.
- `--primary-foreground`: `#fffbeb` - Text on top of primary buttons.
- `--muted`: `#292524` - For secondary inactive areas.
- `--muted-foreground`: `#a8a29e` (`stone-400`).

### Light Mode

- `--background`: `#fafaf9` (Cream / Bone / `stone-50`).
- `--card`, `--popover`: `#ffffff` - Pure white or very close to it for panels.
- `--border`: `#e7e5e4` (`stone-200`).
- `--primary`: `#d97706` (Amber).
- `--muted`: `#f5f5f4`.
- `--muted-foreground`: `#78716c` (`stone-500`).

## 3. Structural Layout

### Navbar (Top)

- **Style:** Minimalist.
- **Contents:** Logo (accentuated in Amber), Theme Toggle (Sun/Moon icon to switch between Mocha and Cream), and primary actions (e.g., "Export", "Preview").
- **Visuals:** Uses the `--card` background color and a bottom `--border`.

### Sidebars (Tools & Properties)

- **Style:** Distinct from the canvas.
- **Visuals:** Uses the `--card` background color. The border radius on internal elements (like draggable tool buttons) will use the default Shadcn radius (e.g., `0.5rem`) to maintain the soft aesthetic. No harsh, sharp corners for interactive elements.

### The Canvas (Central Editing Area)

- **The Environment:** The area _behind_ the email being edited will use the application's `--background` color (Mocha in dark mode).
- **The Email Container:** The actual email document being assembled MUST have a distinct background (usually white `#ffffff` or a very light gray defined by the user's email settings) so it stands out strongly against the Mocha environment. This provides an accurate preview of how the email will look in most clients.
- **Drag & Drop Interactions:** When dragging a component from the sidebar over the canvas, the drop indicator (where the component will land) will be a bold line or highlight in the `--primary` (Amber) color. This provides clear, satisfying, and unmistakable feedback.
